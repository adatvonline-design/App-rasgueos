# Rasgueo·Lab 🎸

App interactiva para visualizar y practicar patrones 
de rasgueo en guitarra.

## Funciones
- Editor visual de patrones con flechas ↓ ↑
- Metrónomo integrado con acento en el 1er tiempo
- Corcheas (notación "y") por tiempo
- Exportar como imagen
- Guardar y cargar configuraciones
- **Ritmos del método**: los 24 patrones del Método de rasgueos (pop, rock, cumbia, reggae, ska, vals, 6/8, country, ranchera, bolero, huapango, rumba, bossa nova, funk y shuffle) con metrónomo, sonido y tempo ajustable. `?preset=P01` abre uno directo.

Los presets los genera `tools/construir_presets_app.py` del vault (`cerebro-wiki`) desde `tools/metodo_rasgueos_datos.json`, el mismo archivo que imprime el PDF. No se editan a mano aquí.

## Uso
Abre directamente en cualquier navegador — sin instalación.
