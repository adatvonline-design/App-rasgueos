# Patrón Rítmico 🎸

App interactiva para visualizar y practicar patrones 
de rasgueo en guitarra.

## Funciones
- Editor visual de patrones con flechas ↓ ↑
- Metrónomo integrado con acento en el 1er tiempo
- Corcheas (notación "y") por tiempo
- Exportar como imagen
- Guardar y cargar configuraciones

## Uso
Abre directamente en cualquier navegador — sin instalación.
